## What's new

- Test builds of Sterling Quest Sync (versions like 0.3.17.01) now show as installed, and the app keeps them updated.
- The code is easier to read: Sterling code style (4 spaces, braces on their own line, grouped lines), clearer names and a short comment on every function. Nothing changes in how the app works.

## Install or update

- **Already have the app (0.1.24 or newer):** it offers this update on Home, or click **Check for updates** in Settings.
- **New, or on 0.1.23 or older:** download `SterlingQuestSync_0.1.29_x64-setup.exe` below and run it. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**. Your settings and partners stay.
- The Companion is optional and works with the [Sterling Quest Sync](https://github.com/SterlingAddons/SterlingQuest) add-on. Setup, troubleshooting and privacy: [the app's page](https://github.com/SterlingAddons/SterlingQuestSync-App#readme).

`latest.json` and the `.sig` file are for the app's own updater; you don't need to download them.
