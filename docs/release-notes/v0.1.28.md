## What's new

- If Start with Windows is turned off in Task Manager or Windows Settings, the app leaves it off and says so in Settings.
- News banners on Home now also arrive with every sync.
- New screenshots on the app's page.

## Install or update

- **Already have the app (0.1.24 or newer):** it offers this update on Home, or click **Check for updates** in Settings.
- **New, or on 0.1.23 or older:** download `SterlingQuestSync_0.1.28_x64-setup.exe` below and run it. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**. Your settings and partners stay.
- The Companion is optional and works with the [Sterling Quest Sync](https://github.com/SterlingAddons/SterlingQuest) add-on. Setup, troubleshooting and privacy: [the app's page](https://github.com/SterlingAddons/SterlingQuestSync-App#readme).

`latest.json` and the `.sig` file are for the app's own updater; you don't need to download them.
