## What's new

- Updates are sturdier: the app asks Sterling's own server where the newest version is, with GitHub as a backup, and tries again if the first try fails.
- If an update still fails, Home says why and offers the download to install it yourself.

## Install or update

- **Already have the app (0.1.24 or newer):** it offers this update on Home, or click **Check for updates** in Settings.
- **New, or on 0.1.23 or older:** download `SterlingQuestSync_0.1.26_x64-setup.exe` below and run it. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**. Your settings and partners stay.
- The Companion is optional and works with the [Sterling Quest Sync](https://github.com/SterlingAddons/SterlingQuest) add-on. Setup, troubleshooting and privacy: [the app's page](https://github.com/SterlingAddons/SterlingQuestSync-App#readme).

`latest.json` and the `.sig` file are for the app's own updater; you don't need to download them.
